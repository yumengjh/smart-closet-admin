# 创作模型能力的选择与验证

## 使用说明

新建模型能力时，可以复用普通生图当前默认的供应商和模型，也可以从已配置的供应商及其允许模型中单独选择。页面只读取可用选项，不提供密钥、服务地址或任意模型名输入。

保存时会把当前选中的供应商和模型写入这条能力记录。以后调整普通生图默认值，不会静默改写已保存能力、已发布模板或历史任务的模型快照。

输出参数是本条能力的覆盖项。留空或填写 `{}` 都表示继承供应商默认参数；填写时须为 JSON 对象。单纯选中一个模型不会自动标记为已验证；多参考图能力仍须人工验证。

编辑已有能力时保留原供应商和模型。若该组合已不在当前可选配置中，页面会阻止保存；先恢复相应生图配置再编辑。需要更换能力身份时，应新增另一条能力。

没有可用生图配置时不能新增能力；读取选项失败时可重试。请先在普通生图配置中登记可用供应商和默认模型。

# 鱼搭完整管理接入

前端只调用 `smart-closet-admin-server` 的 `/api/v1/closet`，密钥由后端持有。正式接口与开关配置见相邻管理后端 `docs/api/closet-integration.md`。

## 页面

- `/closet/dashboard`：汇总大屏、16 个指标、24 小时/30 天趋势、衣柜分布及运维摘要。自动刷新跟随服务建议，隐藏/退出暂停，失败后可重试。
- `/closet/insights`：保留衣柜与搭配使用统计，新增推荐效果、来源/排序/模板分析、每日推荐采用趋势、AI 功能用量与零模型推荐占比。趋势支持 15 个指标和日/周/月。
- `/closet/users`：保留已有业务账号、状态、角色、会话、便携链接、密码、额度管理。
- `/closet/ops`：只读服务健康、模型与内存、索引队列、分页任务及操作日志。
- `/closet/exports`：最长 366 天宽表查询、CSV 下载、去标识事件筛选和游标翻页、本页 JSON 下载。
- `/closet/templates`：模板筛选、槽位与来源详情、审核状态/启用/加分编辑。写入需要 closet:templates:write；只读可查看详情。
- `/closet/style-terms`：风格词审核（鱼搭 #173）。助手从用户对话学到的风格词在这里批准或驳回；列表给出词、映射到的风格、提出次数与人数、首次/最近提出时间，以及全站词表已有映射（批准将替换）。支持单个批准、改映射后批准、驳回和批量批准/驳回（逐项独立处理）。读取需要 closet:styleterms:read，写入需要 closet:styleterms:write；页面不显示用户名。

页面统一沿用 Element Plus，使用现有 ECharts 组件。权限与动态菜单由后端提供，SUPER_ADMIN 在集成开启后获得全部权限。大屏/导出不会调用用户明细、任务所属账号或 AI topUsers 来拼接数据。

## 运行与检查

```sh
VITE_API_TARGET=http://127.0.0.1:8081 pnpm dev
pnpm typecheck
node --test scripts/*.test.mjs
pnpm build
```

新增契约检查覆盖 26 个 HTTP 操作（加 CSV 格式）及 6 个组件键。后端 HMAC、页码转换、权限、部分审核写入、CSV 与默认关闭行为有集成测试。

## 可视化布局改进（2026-10-10）

大屏首屏采用紧凑的核心指标摘要、业务活动面积折线图和品类环形图。补充推荐来源的展示/采用双条形图，颜色/季节切换为横向条形图；16 个指标仍全部保留。洞察页将趋势提前，推荐来源/排序/模板直接切换图表，AI 使用 Token 堆叠条形图和零模型占比环形图，完整明细和统计口径可以展开。统一 Remix 图标、图表配色和圆角面板，适配手机及深色主题。

图表等容器有尺寸后初始化，跟随布局尺寸变化，响应主题切换和减少动态效果设置。ECharts 6 使用 outerBounds 布局。推荐来源字段按真实上游的 source 读取。

验证：typecheck、局部 ESLint/Stylelint、生产构建、13 个现有契约脚本通过。通过真实的隔离鱼搭服务 → 管理后端 → 浏览器验证：桌面 1470×1000、手机 390×844、深色主题、24 小时/30 天切换、推荐来源/排序/模板、季节切换、全屏进入/退出及未来日期无数据状态。截图位于忽略的 output/playwright；有数据截图使用 /tmp/closet-phase2-e2e 中专门写入的合成样例，生产页面不内置演示数据，未修改 8080 现有业务服务。
